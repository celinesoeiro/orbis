# Orbis

A personal finance dashboard for understanding not only where your money is today,
but whether your current decisions are moving you toward your financial goals.

## Why Orbis

Most finance dashboards describe the past.
Orbis is designed around financial position, behavior and direction.

## Core domains

- Accounts
- Credit cards
- Transactions
- Budgets
- Investments
- Debts
- Net worth
- Financial goals

## Stack

Next.js 16 · React 19 · TypeScript · Tailwind CSS

## Status

🚧 Active development

Current focus: application foundation and transaction management.

## Engineering goals

- Feature-oriented architecture
- Strong type safety
- Server-first data access
- Accessible component system
- Automated testing
- CI/CD
- Clear separation between domain and UI concerns
